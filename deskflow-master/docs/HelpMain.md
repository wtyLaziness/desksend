# DeskSend 帮助

DeskSend 支持在 Windows、macOS 和 Linux 电脑之间共享键鼠、传输文件，并显示拖拽和传输状态。

## 连接电脑

1. 两端使用相同版本的 DeskSend。Windows 使用完整便携包时，先完整解压，再运行 `DeskSend.exe`。使用 MSI 安装版时，直接运行已安装的 `DeskSend.exe`。
2. 主机选择共享此计算机的键盘和鼠标，在“配置服务器”中添加副机，并按实际屏幕位置排列。屏幕名称与副机显示的计算机名一致。
3. 副机选择使用另一台电脑的键鼠，填入主机局域网 IP 并启动。首次 TLS 连接时核对证书指纹。
4. 主机放行入站 TCP 24800；双向传文件时，主机和副机都需放行入站 TCP 53318。

## 发送文件

Windows、macOS 和 Linux 之间可互传文件。

- **跨屏边缘拖拽**支持 Windows、macOS 和 Linux X11 会话。macOS 需在“系统设置 → 隐私与安全性 → 辅助功能”中授权 DeskSend。
- **直传**支持以上三个系统，包括 Linux Wayland。Linux 原生边缘拖放仅在 Qt 使用 `xcb` 后端时启用。连接后，选择“文件 → 发送文件...”可挑选本地文件。也可把本地文件或包含可传输文件的文件夹拖入 DeskSend 主窗口。远程 URL 和已不存在的路径会被忽略。只有一个目标时直接发送，有多个目标时选择接收电脑。支持主机与副机双向发送，也支持连接同一主机的副机之间互传。

三端的接收方都需允许可信局域网入站 TCP 53318。Windows MSI 安装版会添加防火墙规则，便携版需检查程序放行设置。macOS 可在应用防火墙中允许接收程序的入站连接，Linux 可在 UFW 或 firewalld 中按局域网范围放行该端口。

### 跨屏拖拽

使用主机共享的鼠标，在主机或副机的桌面、文件管理器中拖起文件或文件夹，跨入目标屏幕后松手。副机自己的实体鼠标不能独立发起跨屏切换。

进入目标屏幕后，光标旁显示松手接收提示；松手后显示准备接收、进度和结果。松手前按 Esc 或拖回源屏可取消跨屏发送。传输开始后，可以在任一端的进度窗点击「取消传输」。源文件和已收完的文件会保留，未收完的文件会清理。

| 接收系统 | 跨屏拖拽落点 | 默认目录与剪贴板回退 |
| --- | --- | --- |
| Windows | 资源管理器文件夹或桌面 | 其他窗口和直传默认保存到“下载”，并写入 `CF_HDROP` 文件剪贴板 |
| macOS | 指针坐标命中的 Finder 桌面，或能按窗口边界唯一匹配的 Finder 文件夹窗口 | 其他窗口和直传默认保存到“下载”，并写入系统文件 URL 剪贴板 |
| Linux | X11 会话中识别到的桌面 | 其他窗口、Wayland 或直传默认保存到“下载”，并写入 Qt 文件 URL 和 `x-special/gnome-copied-files` 剪贴板 |

系统未提供“下载”目录路径时，默认接收目录回退到桌面。空文件夹不传输。

多台副机连接同一主机时，可拖着副机 A 的文件穿过主机屏幕，到副机 B 松手；中途保持左键按下，文件由源电脑直传最终接收电脑。

文件传输期间，Windows 会为键鼠连接请求更高的网络优先级。效果取决于网络设备的支持，文件传输没有固定速率上限。

## 更新与迁移

在“帮助 → 检查 DeskSend 更新…”中下载并安装；英文入口为 `Help → Check for DeskSend Updates...`。请先等待文件传输结束。

手动换目录升级时，退出旧程序，将新包完整解压，并复制旧目录的整个 `settings/` 到新目录。不要只复制 EXE，不要改名 `settings/Deskflow.conf`。便携版不安装服务，不能控制登录界面、锁屏或 UAC 安全桌面。

使用 MSI 安装版时，在副机以管理员身份运行 DeskSend，在“编辑 → 首选项 → 高级”开启后台服务，并勾选“始终以系统身份运行（支持登录界面和 UAC）”，再连接主机。安装版同样可通过“帮助 → 检查 DeskSend 更新…”下载并运行新版 MSI 升级，不要将便携版的 `settings/` 复制到安装目录。

标题栏的关闭按钮默认将窗口收进托盘。托盘菜单中的“退出”会停止键鼠核心和 DeskSend 后台服务。服务随键鼠共享按需启动。

## 打开管理员程序后无法跨屏

如果在 Geek Uninstaller 等管理员程序的窗口上无法跨屏，请在出现问题的电脑上从托盘退出 DeskSend，再右击 `DeskSend.exe` 选择“以管理员身份运行”。恢复连接后，让该程序保持在前台，再从屏幕边缘试一次。副机的 UAC 确认框需要安装版的后台服务。
